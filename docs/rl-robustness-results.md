# 강화학습 강건성 실험 결과

**실행일:** 2026-07-30  
**대상:** 삼성전자 `005930`, feature schema 3, 6단계 목표 비중 환경

## 1. 먼저 바로잡은 현재 성적

과거 메모의 `RL +2.08% / Buy & Hold -5.25%`는 현재 데이터 경계와 같은 결과가
아니다. 현재 240거래일 데이터를 다시 70/15/15로 분할해 동일 코드로 평가한
36거래일 Test 결과는 다음과 같다.

| 정책 | Test 수익률 | MDD | Turnover |
| --- | ---: | ---: | ---: |
| 현금 100% | 0.00% | 0.00% | 0.00 |
| 고정 20% | +1.04% | -5.79% | 0.20 |
| 고정 40% | +2.08% | -10.89% | 0.40 |
| 고정 60% | +3.12% | -15.42% | 0.60 |
| 고정 80% | +4.15% | -19.47% | 0.80 |
| Buy & Hold 100% | +5.19% | -23.10% | 1.00 |
| 기존 최신 RL artifact | **-9.38%** | -29.13% | 60.17 |

현재 기준에서 기존 RL은 고정 비중 전략보다 낮고 거래도 지나치게 많다.

## 2. 시장 국면 확인

고정 분할의 기초자산 수익률은 다음과 같다.

| 구간 | 거래일 | 시장수익률 | 상승일 비율 | 장중수익률 중앙값 |
| --- | ---: | ---: | ---: | ---: |
| Train | 168 | **+220.32%** | 54.76% | +0.21% |
| Validation | 36 | +40.05% | 44.44% | -0.17% |
| Test | 36 | +5.63% | 47.22% | -0.25% |

Train은 매우 강한 상승장이다. 세 expanding walk-forward fold의 Train 수익률도
각각 `+169.16%`, `+220.32%`, `+247.01%`였다. 마지막 fold의 Test 시장수익률은
`-19.37%`다. 따라서 학습 분포와 마지막 미래 평가 분포의 차이가 매우 크다.

## 3. 새로 적용한 검증 방식

- 현금 및 고정 20·40·60·80·100% baseline 추가
- 과거 변동성만 사용하는 causal volatility-scaled baseline 추가
- Test가 겹치지 않는 3개 expanding walk-forward fold 추가
- Validation을 3개 하위 기간으로 나누어 중앙 수익률 계산
- 중앙 수익률에서 MDD와 turnover를 차감하는 checkpoint 안정성 점수 적용
- seed마다 모델을 처음부터 다시 학습하는 독립 multi-seed 실행기 추가
- 각 실행 후 결과를 즉시 JSON에 저장해 중단 시에도 완료 결과 보존

Checkpoint 선택 점수는 다음과 같다.

```text
selection_score
  = validation 하위 구간 수익률 중앙값
  - 0.25 × |전체 validation MDD|
  - 0.001 × 전체 validation turnover
```

## 4. Entropy 선별 실험

각 설정을 50,000스텝, seed 42, 3개 walk-forward fold에서 비교했다.

| `ent_coef` | Test 수익률 중앙값 | 최악 Test | MDD 중앙값 | Turnover 중앙값 | Buy & Hold 승률 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | -12.04% | -20.91% | -14.22% | 78.12 | 0/3 |
| 0.001 | -8.06% | -23.20% | -14.26% | 88.94 | 0/3 |

`0.005`가 세 후보 중 상대적으로 나았지만 어떤 설정도 Buy & Hold 또는 고정 80%를
이기지 못했다. 설정 변경만으로 일반화 문제가 해결되지 않았다.

## 5. 독립 seed 결과

선별된 `ent_coef=0.005`를 독립 seed `11, 22, 33, 44, 55`로 다시 학습했다.
사용자 요청에 따라 오래 걸리는 실행을 15개 중 13개 완료 시점에 중단했다.

완료된 두 fold의 결과는 다음과 같다.

| Fold | Seed별 Test 수익률 | 중앙값 | 고정 80% 승리 |
| ---: | --- | ---: | ---: |
| 1 | -19.95, -19.02, -3.87, +1.77, -11.60% | **-11.60%** | 0/5 |
| 2 | -11.69, +5.57, -1.66, -1.67, -1.03% | **-1.66%** | 0/5 |

마지막 하락 Test fold에서 완료된 seed 11·22·33은 각각 `-42.58%`, `-28.66%`,
`-32.67%`를 기록했다. 완료된 13개 모델 중 Buy & Hold나 고정 80%를 이긴 모델은
없었다. 전체 수익률 중앙값은 `-11.60%`, 최악 결과는 `-42.58%`, turnover
중앙값은 `92.34`였다.

## 6. 결론

현재 PPO 정책은 수익 전략으로 유효하지 않다. 핵심 원인은 다음 세 가지다.

1. Train이 `+220%`의 극단적인 상승장이라 다양한 시장 국면을 학습하지 못한다.
2. seed에 따라 Test 결과가 20%p 이상 달라져 정책 학습이 불안정하다.
3. turnover가 고정 비중 전략보다 수십~수백 배 높아 비용과 타이밍 손실이 크다.

현재 단계에서 300,000스텝으로 학습시간만 늘리거나 feature를 무작정 추가하는 것은
우선순위가 아니다. 다음 실험은 더 긴 하락·횡보 데이터 확보, 시장 상대 보상
ablation, turnover 억제, 그리고 동일한 multi-seed walk-forward 평가 순서로
진행해야 한다. 이 검증을 통과하기 전에는 실거래 모델로 사용하지 않는다.
